# Código de conduta

O Sururu existe para que mais gente aprenda tecnologia. Por isso, aqui todo
mundo é bem-vindo, do primeiro `ls` ao cluster em produção.

## O que esperamos

- Respeito e paciência, principalmente com quem está começando.
- Críticas ao código e às ideias, nunca às pessoas.
- Ajudar sem humilhar. "Leia o manual" não é resposta; o link certo do manual é.

## O que não aceitamos

Assédio, preconceito de qualquer tipo (origem, sotaque, região, gênero,
orientação, raça, religião, idade, deficiência, nível de experiência),
ataques pessoais e exposição de dados de outras pessoas.

## Como relatar

Escreva para contato@kurumintecnologia.com.br. Todo relato é tratado com
sigilo. Quem descumprir este código pode ser advertido ou removido do projeto.

Baseado no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), versão 2.1.

# Apoie o projeto

O Sururu é e vai continuar **gratuito**. A ISO, o código e os laboratórios são
livres para baixar, usar em sala de aula, copiar e modificar.

Se ele te ajudou a passar numa prova, a conseguir uma vaga ou só a perder o
medo do terminal, um café ajuda a manter o projeto vivo.

## Outras formas de ajudar (que valem tanto quanto)

- **Dê uma estrela** no [repositório](https://github.com/kurumintecnologia/sururu-linux).
  É o que faz o projeto aparecer para mais gente.
- **Conte para alguém.** Um post no LinkedIn dizendo como você usou vale muito.
- **Leve para a sua turma.** Professor? O Sururu foi pensado para laboratório de escola.
- **Contribua** com um laboratório, uma correção ou um teste num computador
  diferente. [Veja como](contribuir.md).

## Para onde vai o dinheiro

| Gasto | Para quê |
|---|---|
| Hospedagem e banda das ISOs | Download rápido, com espelho no Brasil |
| Ferramentas de desenvolvimento | Assinaturas usadas para construir e testar o Sururu |
| Pendrives | Oficinas gratuitas em escolas públicas e institutos federais |
| Tempo | Escrever laboratórios novos e manter os antigos funcionando |

O que entrar e o que sair vai ser publicado aqui, com transparência, a cada
versão do Sururu.

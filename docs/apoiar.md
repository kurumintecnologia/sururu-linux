# Apoie o projeto

O Sururu é e vai continuar **gratuito**. A ISO, o código e os laboratórios são
livres para baixar, usar em sala de aula, copiar e modificar.

Se ele te ajudou a passar numa prova, a conseguir uma vaga ou só a perder o
medo do terminal, você pode ajudar a manter o projeto vivo:

- **Pague um café** pelo Pix ou pelo link de apoio na página do GitHub
  (botão **Sponsor**).
- **Dê uma estrela** no [repositório](https://github.com/kurumintecnologia/sururu-linux).
  Parece pouco, mas é o que faz o projeto aparecer para mais gente.
- **Conte para alguém.** Um post no LinkedIn dizendo como você usou vale muito.
- **Leve para a sua turma.** Professor? O Sururu foi pensado para laboratório
  de escola.

## Para onde vai o dinheiro

Servidor para hospedar as ISOs, domínio, pendrives para oficinas gratuitas e
tempo para escrever laboratórios novos. O que entrar e o que sair vai ser
publicado aqui, com transparência.

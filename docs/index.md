# Sururu Linux

![Sururu Linux](img/sururu-logo.svg){ width="420" }

**Linux, containers e Kubernetes sem bicho de sete cabeças.**

O Sururu é uma distribuição Linux brasileira, baseada no Debian, feita para
quem quer aprender infraestrutura moderna. Você grava num pendrive, dá boot e
em poucos minutos tem um cluster Kubernetes de verdade rodando, com
laboratórios guiados em português que se corrigem sozinhos.

![Central Sururu](img/central-inicio.png)

## Para quem é

- Quem está saindo do Windows e quer aprender Linux de verdade, pelo terminal.
- Quem estuda Docker, containers e Kubernetes e cansou de perder a tarde
  montando ambiente.
- Quem se prepara para LFCS, KCNA, CKA ou CKAD e quer treinar com cronômetro.
- Professores e escolas que precisam de um laboratório igual para a turma
  inteira, que roda até sem internet.

## O que vem nele

| | |
|---|---|
| **Central Sururu** | Painel em português: cria o cluster com um clique, mostra nós e pods, laboratórios com correção automática e modo prova |
| **Ferramentas prontas** | `kubectl`, `kind`, `helm`, `k9s`, `docker`, `podman`, `jq`, `yq` |
| **Desktop leve** | XFCE com barra embaixo, menu com busca, ícones Papirus. Roda em notebook simples |
| **Em português** | Teclado ABNT2, fuso de Brasília e tudo traduzido desde o primeiro boot |
| **Base Debian 13** | Estável, com atualizações de segurança direto do Debian |

## Por que "Sururu"?

O sururu é o marisco das lagoas de Alagoas, a terra de quem começou o projeto.
A concha do logo tem as linhas de crescimento ligando três nós, como um
cluster, e uma pérola amarela na ponta: o sol de Alagoas. No papel de parede,
a trama do céu é o filé, o bordado de rede alagoano, que também é a malha de
nós de um cluster.
